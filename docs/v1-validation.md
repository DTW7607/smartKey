# 首版实现与验证记录

日期：2026-09-07。版本：0.2.0（本地内测构建）。

## 已实现

- 独立 `SmartKeyActions` library：动作定义、Provider、能力/参数版本、注册、统一执行和结果。
- 设置窗口三页：通用、动作绑定、脚本管理；公开 Liquid Glass 材料、标准窗口与菜单快捷键。
- 三手势绑定键盘、多媒体、脚本或无；1–8 字动作名称；双击 conf 自动联动；手势内配置快照。
- 脚本托管副本、新建/导入/拖入/复制/重命名/删除/导出；默认应用打开，外部原子保存监听；无内置代码预览/编辑。
- 后台脚本、最新磁盘内容快照、工作目录/环境参数、输出截断、超时、停止与受管进程组清理。
- 动作名称/状态气泡，低频冷却；空绑定不产生气泡；保留设备配置和音频守卫。
- 移除旧气泡/面板的私有材质与焦点选择器，减少动态效果时降低位移/形变。
- 单独构建脚本和源码扩展示例；尚未安装覆盖 `/Applications` 中的现有程序。

## 自动化结果

最终测试命令：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
CLANG_MODULE_CACHE_PATH=/tmp/smartkey-module-cache \
SWIFTPM_MODULECACHE_OVERRIDE=/tmp/smartkey-module-cache \
swift test --disable-sandbox
```

成功退出。Swift Testing 报告 71 项（其中真实 HID 集成 1 项跳过），XCTest 5 项通过，即 75 项执行通过、1 项未运行。没有测试失败。测试日志：`/tmp/smartkey-v1-final-tests.log`。

覆盖手势中配置改变/重置、绑定/双击联动、坏配置备份恢复、新 schema 拒绝降级、脚本引用、导入导出、默认参数、外部连续原子保存、执行快照、cwd/$0、stdout/stderr、退出码、超时、取消、防重入、大输出、忽略 TERM 子进程与正常退出后的后台清理。

测试使用临时脚本与配置；没有发送真实键盘/媒体事件，没有运行用户脚本，没有抢占真实 HID，也没有修改音频路由。`--disable-sandbox` 用于解决当前受限环境中 SwiftPM 再次启动 sandbox-exec 失败的问题，不改变产物的权限策略。仅有 SwiftPM 用户缓存目录不可写提示，源文件编译无警告。

## 首版明确限制

- 后台非交互 Shell 脚本，不管理主动脱离进程组的守护服务，不撤销已发生的脚本副作用。
- 运行内容为磁盘快照；未保存的外部编辑不可见；不保证识别所有非原子保存的中间状态。
- 默认应用由系统决定，可能是执行型终端，智键不会擅自改关联或改用内置编辑器。
- 配置导出不包含环境变量或外部依赖；手动编辑动作 JSON 需重启。
- 元信息草稿只在当前应用会话中保留，退出前应点击保存信息；程序不保存外部编辑器草稿。
- 首版不包含多方案、宏编辑器、动态插件、USB/蓝牙按键或云能力。
